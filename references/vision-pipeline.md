# Agent-Native 视觉直接解析流水线指南 (Vision Pipeline)

## 1. 为什么采用 Agent-Native 视觉解析？

传统 PDF 解析在遇到扫描版、纯图片、复杂表格、多栏公式或目录印错时，通常依赖本地安装的 OCR（如 Tesseract、PaddleOCR）或第三方在线 API（如 MinerU）。但这存在明显痛点：
- **Tesseract/PaddleOCR**：需要本地环境配置、安装语言包，字符识别容易错漏，且完全丢失多栏排版、复杂表格和标题层级，输出“碎字符堆”；
- **第三方在线 API**：有网络延迟、文件大小限制、Token 消耗或排队问题。

### 🌟 Agent-Native 视觉的核心优势
由于本模型/Agent **原生具备强大的多模态视觉能力**，可以直接“看”高分辨率图片：
1. **零外部环境依赖**：只需 `pymupdf` 将 PDF 页面渲染为 PNG，无需安装任何复杂 OCR 二进制软件；
2. **高保真版面与语义理解**：直接看清多栏排版、图表插图、代码缩进、数学公式、印章与手写批注；
3. **精准页码核验与漂移自愈**：直接阅读页面顶部的页眉和底部的印刷页脚，一目了然验证逻辑页码与物理页偏移；
4. **一键生成结构化 Markdown**：视觉直接转写即可得到标准的 `#` 标题、Markdown 表格、LaTeX `$$...$$` 公式。

## 2. Agent 视觉流水线工作流 (SOP)

```text
遇到扫描件 / 无文字层 / 复杂排版 / 书签异常？
       │
       ▼
1. 页面高保真渲染 (Render)
   python scripts/render_page.py "book.pdf" -c "2.3.2" --dpi 150
   # 或容错范围传参：
   python scripts/render_page.py "book.pdf" 38 40 --dpi 150
       │
       ▼
2. Agent 原生视觉读取 (Vision Inspection)
   - 检查目录页逻辑页码
   - 检查正文首页标题与页脚数字 (Sanity Check)
   - 提取/转写目标正文内容
       │
       ▼
3. 结构化 Markdown 交付 (Deliver)
   - 输出保留排版、表格与公式的高质量 Markdown
```

### 扫描件智能降级与协同输出 (extract_chapter.py)
在调用 `extract_chapter.py` 时，若探测到目标页码文字层为空（纯图片扫描版），脚本将自动执行智能协同输出：
- 自动渲染目标页码为高清 PNG 原图；
- 提示 Agent 多模态视觉直读原图路径；
- 底部附带本地 RapidOCR/兜底引擎提取的离线文字通道，方便快速浏览与关键信息对照。

## 3. 适用场景推荐

| 场景 | 推荐操作 |
|---|---|
| **扫描版无书签目录提取** | 渲染前 15 页中包含“目录”的页面图片 $\to$ Agent 视觉直读提取“章节名 $\to$ 逻辑页码” |
| **Offset 漂移核验** | 渲染目标章节首页 $\to$ Agent 视觉核对页脚印刷数字与大标题是否吻合 |
| **复杂图表/公式页面解析** | 渲染目标页为 PNG $\to$ Agent 视觉理解架构图/拓扑图并给出详细文字拆解 |
| **短章节高质量转写** | 渲染章节对应页面 $\to$ Agent 视觉转写为高保真 Markdown |
